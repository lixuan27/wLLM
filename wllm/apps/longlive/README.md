# LongLive

Narrated video generation. You speak prompts into your mic; ASR
transcribes them, and the [LongLive-2.0-5B](https://huggingface.co/Efficient-Large-Model/LongLive-2.0-5B) model generates a continuous
video stream that follows the current prompt. Speak a new prompt and
the video changes course without stopping.
